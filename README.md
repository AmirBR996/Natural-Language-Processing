# Natural Language Processing

A comprehensive collection of Jupyter notebooks demonstrating various Natural Language Processing (NLP) techniques and algorithms.

## Project Structure

This repository contains the following notebooks:

- **Tokenization.ipynb** - Breaking text into individual tokens (words, sentences)
- **Stemming.ipynb** - Reducing words to their root form using stemming algorithms
- **Lemmatization.ipynb** - Converting words to their base form using lemmatization
- **Stopwords.ipynb** - Identifying and removing common words that add little value
- **POS_tagging.ipynb** - Part-of-speech tagging to identify word types
- **name_entity_recognization.ipynb** - Named Entity Recognition (NER) for identifying entities like names, locations, organizations
- **Word2vec.ipynb** - Word embeddings using Word2Vec for semantic representations

## Requirements

All dependencies are listed in `requirement.txt`. To install them, run:

```bash
pip install -r requirement.txt
```

## Getting Started

1. **Set up a virtual environment** (recommended):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirement.txt
   ```

3. **Launch Jupyter Notebook**:
   ```bash
   jupyter notebook
   ```

4. **Open any notebook** to explore specific NLP techniques.

## Usage

Each notebook is self-contained and demonstrates a specific NLP concept with:
- Explanations of the technique
- Code examples
- Sample outputs

You can run the notebooks sequentially or independently based on your interests.
